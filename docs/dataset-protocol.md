# Протокол сбора датасета таджикского жестового языка (черновик v0.1)

Статус: черновик для обсуждения со специалистами. Текст согласия и сроки хранения должен проверить юрист.

## 1. Принципы
1. Только добровольцы, только письменное согласие до записи. Без согласия записи нет.
2. Для MVP — только совершеннолетние участники. Для несовершеннолетних нужно согласие родителей или опекунов и отдельное решение организаторов.
3. Список жестов определяют носители языка и специалисты, а не разработчик. Я не придумываю значения жестов и не смешиваю их с жестами других языков.
4. Хранятся ключевые точки. Видео хранится только пока нужно для проверки разметки, затем удаляется (если участник не разрешил дольше).
5. Участник может отозвать согласие в любой момент: его образцы удаляются (см. `revoke_consent` в БД). Юридическая формулировка о влиянии на уже обученные модели — вопрос к юристу.

## 2. Кого привлекать (контактов пока нет, ищем сами)
- Организации и школы, работающие с глухими и слабослышащими людьми.
- Переводчики жестового языка, носители языка, студенты соответствующих специальностей.
- Цель MVP: не менее 10 участников, лучше 15–20. В конфигурации по умолчанию на новый жест нужно ≥3 человека и ≥15 образцов; эти пороги стартовые и подлежат проверке экспериментом.

## 3. Условия записи
- Расстояние: верх тела, оба плеча и обе кисти в кадре. Камера на уровне груди-плеч, 25–30 к/с.
- Разные условия намеренно: 2–3 фона, дневной и комнатный свет, 2 типа устройств (телефон, веб-камера), разная одежда.
- Каждый жест: 10–15 повторов за 2 сессии в разные дни, плюс 5–10 «негативных» записей (случайные движения, пауза, жесты вне словаря). Негативы нужны для порогов отказа.
- Жест записывается с покоем в начале и конце (≈0,5 с).

## 4. Конвейер
1. Запись через приложение или загрузка mp4/webm (проверка по сигнатуре файла, до 30 МБ).
2. Автоматический контроль качества (`signml/qc.py`): длительность, частота кадров, видимость плеч и рук, движение, освещённость, резкость.
3. Извлечение ключевых точек (`signml/extract.py`).
4. Разметка: два независимых разметчика; согласие измеряется коэффициентом Коэна κ (`metrics.cohen_kappa`). Спорные образцы решает носитель языка. Целевое значение κ задаёт методика, число заранее не заявляем.
5. Заморозка версии датасета: разбиение по ЛЮДЯМ (`splits.assign_signer_splits`), проверка `v_split_signer_leakage` = пусто, `coverage_report` без непокрытых жестов.
6. Обучение, калибровка порогов на валидации, оценка на тесте, проверка условий публикации.

## 5. Что нельзя
- Включать в датасет записи без согласия или от отозвавших согласие.
- Давать администратору доступ к видео обычных пользователей (они не сохраняются).
- Заявлять поддержку таджикского жестового языка до подтверждённой валидации датасета (`evidence_status = 'validated'`).
